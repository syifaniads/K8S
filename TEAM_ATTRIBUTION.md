## Attribution model

The repository distinguishes three kinds of material:

1. **Lecturer/course reference material** — generic installation and load-balancing instructions that the assignment explicitly asked students to follow.
2. **Collaborative lab implementation** — Kubernetes manifests, workload configuration, autoscaling setup, load-balancing experiments, and troubleshooting performed in the course environment.
3. **Portfolio curation** — the current documentation that explains the architecture, evidence, limitations, and security cleanup for recruiter review.
